# Fluent Emoji 3D pictures

From Microsoft's Fluent Emoji (https://github.com/microsoft/fluentui-emoji), MIT licence, Copyright (c) Microsoft Corporation.
Upscaled from 256 px to 512 px with light sharpening. Used by `pipeline/sign2_video.py`.
To add a picture: take `assets/<Name>/3D/<name>_3d.png` from that repo, save it here as the lowercase name with underscores, and upscale the same way.
