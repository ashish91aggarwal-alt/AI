# Tarot Talk

Work for the Tarot Talk Instagram channel (tarot, healing, Akashic reading): motion-graphic reel series that end in a comment-to-DM pitch for a paid report or reading.

- `SKILL.md` — copy of the `tarot-motion-series` skill (method, gates, independent-review rule)
- `ideas/` — series idea lists and the 2027 "driver" concept
- `reviews/` — every independent review, dated
- `references/` — reference posts and notes
- `series/2027-driver/` — 2027 New Year series: style frames and their source code
- `dashboard/` — the Tarot Talk workspace dashboard: `workspace.json` (now, playbook of skills and strategies with statuses, process research, strategy, scripts, production), `styles.json` + `img/styles/` (style library posters, credited), `parts/` (page source), `build.py`, and the built `index.html`. Research data comes from `../tarot-talk/scouting/`.
