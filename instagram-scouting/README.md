# Instagram scouting

Shared by all projects in this repo. Method and rules are in `SKILL.md` (a copy of the `instagram-scouting` skill; the skill is the canonical copy).

- `snippets/` — the page snippets the skill runs in the built-in browser: profile list, reel facts, contact sheet.
- `reviews/` — independent reviews of this skill.

Scouting notes are saved inside each project, for example `tarot-talk/references/scouting/`.
